\section{Summary}
\begin{itemize}
    \item \textbf{After the internship, what skills/knowledge did you gain?} Through building AWS CloudHop RAG, I strengthened my hands-on skills across core AWS services (EC2, S3, IAM, VPC endpoints), and picked up new ones including S3 Vectors, S3 Metadata/Annotations, Cost Categories, Glue, Amplify, and Cognito. On the technical side, I designed and implemented an entire multi-hop RAG pipeline myself -- hybrid BM25/dense retrieval, LLM-based query decomposition, an adaptive hop planner, and cross-encoder reranking -- rather than adapting an existing template, and deployed it end-to-end behind a FastAPI backend on EC2 with API Gateway and an Amplify frontend. I also gained practical experience with static-site deployment and CI/CD (Hugo, GitHub Actions), technical writing (two published blog posts and a full workshop write-up), and independent debugging of both infrastructure issues (GitHub Pages build/deploy errors) and pipeline-level failures (retrieval and reasoning errors), including designing for graceful degradation under Free Tier hardware constraints.
    \item \textbf{Personal reflections: about the company, about the internship program?} FCAJ's working environment was friendly and open, and the mentor's guidance style -- explaining concepts clearly, encouraging questions, but letting me try and fix problems myself before stepping in -- was exactly the kind of support that let me learn by doing rather than by being handed answers. The program struck a good balance between structured deliverables (worklogs, workshop labs, blogs) and genuine autonomy in how I approached the RAG project. Overall, the internship gave me a much clearer, more concrete picture of what cloud engineering work looks like day to day, and I would recommend the program to a friend without hesitation.

\end{itemize}
