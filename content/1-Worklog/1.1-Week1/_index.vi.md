  * Compute
  * Storage
  * Networking
  * Database
  * ...

  * Region mặc định
  * ...

  * Tạo EC2 instance
  * Kết nối SSH
  * Gắn EBS volume

* Có khả năng kết nối giữa giao diện web và CLI để quản lý tài nguyên AWS song song.
